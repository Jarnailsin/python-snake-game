# Snake Pro

A Tkinter snake game with difficulty levels, obstacles, power-ups and saved settings.

## Run
    python snake_game.py

Requires Python 3 with Tkinter (included with the standard Windows/macOS installers).
Sound and music use `winsound` and are Windows-only; the game runs silently elsewhere.

## Controls
Arrows / WASD move, Space pause, R restart, Esc menu.

`snake_save.json` (high score and settings) is created automatically on first run.
